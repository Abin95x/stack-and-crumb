## Run

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Stack

Next.js 16 (App Router, TypeScript) · Tailwind CSS 4 · three.js via @react-three/fiber + drei ·
GSAP ScrollTrigger · Lenis smooth scroll.
